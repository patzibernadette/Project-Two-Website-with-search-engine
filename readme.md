2. Overview/Project Description: Vibe Search is a responsive web application that allows users to search fpr GIFS based on a mood or music vibe with anime characters. Users can enter keywords such as "party","chill", or "workout" into the search field, and  the application will fetch and display relevant GIF's using the Giphy API. The project demonstrates how to integrate a third-party API, handle asynchronous JS resquest, parse JSON data, and dynamically render content to the DOM. It also emphasizes responsive design using flexbox and media queries to ensure usability on both desktop and mobile devices.
3. How to Use:1. Enter a mood or vibe into the search input field.
2.Click the Search button.
3.The application sends a request to the Giphy API.
4.Matching GIFs are displayed in a responsive grid layout.
5.Resize the browser window to see the mobile layout adaptation.  
4. Technologies Used : HTML, CSS, Flexbox, Media Queries, JavaScript, Giphy API, Git & GitHub.
